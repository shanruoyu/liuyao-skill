# liuyao-najia-v1 固定装卦规则

本文件规定纳甲装卦；手摇、随机和时间起卦的来源分流见 [起卦入口](casting.md)。传统年月日时法只负责生成本卦与一个动爻，再交本规则装卦。

## 币面、爻序和八宫

一摇三枚，0计2分、1计3分，分值=6+1的个数。6/8阴，7/9阳；6/9翻转。
输入初→上；内部 bits 也是初→上。前三爻下卦，后三爻上卦。

| 三爻下→上 | 卦 | 宫五行 |
|---|---|---|
| 111 | 乾 | 金 |
| 110 | 兑 | 金 |
| 101 | 离 | 火 |
| 100 | 震 | 木 |
| 011 | 巽 | 木 |
| 010 | 坎 | 水 |
| 001 | 艮 | 土 |
| 000 | 坤 | 土 |

八宫各以纯卦为起点，依次翻初、二、三、四、五爻；第五世卦再翻第四爻得游魂，再翻内三爻得归魂。
以初爻为最低位的异或掩码为 [0,1,3,7,15,31,23,16]。
世位依次 [6,1,2,3,4,5,4,3]，应与世相隔三位；六十四个卦形须恰好各归一宫。

以本卦宫五行为我：同我兄弟，生我父母，我生子孙，我克妻财，克我官鬼。
变后重新按上下卦纳甲，但六亲仍用本卦宫五行。这一参照不随变卦独立所属宫改变。

伏神：仅针对本卦缺少的六亲，从本宫纯卦同位借出；保存本卦同位爻为飞神。多处伏神保留，不根据想要的结论选一处。
日月可以按本卦宫五行标外部六亲，输出单列，不伪装成卦中明爻。

## 历法和计算边界

仅 cast_time 为带偏移完整时间时计算历法；先换北京时间 UTC+08:00，再交 lunar_python。
月建按十二节的实际交节时刻；零点换日用 getDayInGanZhiExact2，子初换日用 getDayInGanZhiExact，不能混用。
六神取起卦日干：甲乙青龙、丙丁朱雀、戊勾陈、己螣蛇、庚辛白虎、壬癸玄武，从初爻沿青龙、朱雀、勾陈、螣蛇、白虎、玄武顺布。
旬空取起卦日所属六甲旬缺失二支。月破仅标本爻与月建地支六冲，不据一个标签自动判成败。
未提供时间不影响装卦；此时 calendar.status=missing，时间相关字段为null。日期不完整时要求补全或移除 cast_time 仅看基础盘，不能编造钟时。

v1 未实现旺衰评分、暗动、进退神、三合是否化局、十二长生、应期预测，不以规则名假装已实现。

电子录文有讹字；不把现代增订序当古文。乾宫观卦为风地观；纳甲艮卦不可误读作“辰卦”。

固定检验：
- 需→讼，初到上值 [9,7,9,6,7,6]：需坤宫游魂，世4应1，动1/3/4/6；变爻寅木官鬼、午火父母、午火父母、戌土兄弟。
- 夬→姤，[9,7,7,7,7,6]：夬坤宫五世，世5应2；变爻丑土、戌土仍为兄弟。
- 贲101001：艮宫一世，伏二爻午火父母、三爻申金子孙。
