# 起卦入口与来源

使用 `scripts/casting_cli.py` 处理提问、方法选择和起卦，再由原 `liuyao_cli.py` 排纳甲盘。旧计算器仍接受原有六组输入。

## 分流与选择

- 本次提供 `coins`：先校验并直接排盘，优先于 `casting_method`。非法、缺项、空数组或 null 均报错，不能改为自动起卦。手摇卦没给时间就保留缺失。
- 只有问题且没选方法：返回 `status=awaiting_casting_method`、原问题和三种选择；不读时钟、不生成或解卦。
- 用户明确选择后，模型保留原问题和用神字段，填写 `casting_method` 再调用。默认推荐传统年月日时法；“默认”“按时间”映射到 `time_traditional`，不代表等待期间可以自动选择。
- 三个枚举：`time_traditional`、`random`、`time_seed`。数字菜单由模型按实际展示对应，避免把旧菜单数字当固定算法名。
- 不从上一件事沿用六组或时间。用户明确对同一已起卦问题继续追问时，复用那一卦；输出/解释重试也复用已生成记录，不静默重掷。

## 程序生成的时间

用户明确给出 `cast_time` 时使用它，并标记 `time_source=user_provided`；不把它冒充程序实际生成时刻，`generated_at=null`。
未给出时间时，仅在用户选定生成方式后采一次程序当前时钟，转北京时间 UTC+08:00，精确到秒；起卦、时间种子和历法使用同一时刻，标记 `program_clock`。
时间格式和换日选项沿用原计算器。所有自动生成方式会先检查历法依赖与时间，再生成记录；缺依赖时报错，先修复再起卦。
输出 `casting` 保留方法、算法版本、时间来源、实际使用时刻、六组原始值及其性质；`status=ready` 才有盘面。

## 默认：传统年月日时法

采用[《梅花易数》卷一“年月日時起例”](https://zh.wikisource.org/wiki/梅花易數/卷一#年月日時起例)生成卦，再按六爻纳甲取用神和解读。此为明确的组合口径：不引入梅花体用或互卦断法，不声称是传统铜钱六爻的投掷结果。

- 年数：农历年份地支，子1至亥12；按农历新年换年，不按公历1月1日或立春换年。
- 月数、日数：农历月和日。闰月按所重复的月数计，这是本实现的明确约定，不能称古籍对闰月已有定论。
- 时数：子1至亥12，23:00至00:59为子时。
- 上卦数＝年数＋月数＋日数，除8取余；下卦数再加时数，除8取余；总数除6取动爻。余0分别取8与6。
- 先天卦数：乾1、兑2、离3、震4、巽5、坎6、艮7、坤8。下卦放初二三爻，上卦放四五上爻。
- 默认 `midnight` 零点换日；显式 `zi_start` 时，23点后的农历日期按次日计算，时支仍为子。历法日辰采用相同换日选项。
- 只产生一个动爻。为兼容原计算器，将静阳/静阴编码为001/011，动阳/动阴为111/000；输出标记 `synthetic_line_encoding_not_coin_tosses`。展示上、下卦和动爻，不把六组编码称作“用户摇得的币面”。

独立古例：辰年农历十二月十七申时，年数5、时数9，上卦合数34、总数43，得泽火革，初爻动变泽山咸。

## 程序随机三币

`random` 使用 `secrets.randbits(1)` 独立取18次公平币面，每三位分一组，初爻至上爻。6/7/8/9的理论权重为1:3:3:1；不能直接等概率抽选四种爻态。展示这六组为“程序模拟币面”。

## 自定义时间种子法

`time_seed` 采用 `liuyao-time-seed-v1`：
1. 将时间规范为北京时间、秒精度的ISO字符串。
2. 对 `"liuyao-time-seed-v1\n" + 时间字符串` 的UTF-8字节取SHA-256。
3. 按每个字节高位到低位取前18位，每三位分一组。

相同规范时间产生相同六组；问题文本不参与种子。该算法是本项目自定义的确定性方法，不能称传统年月日时法或真实投币。输出记录 `seed_timestamp` 与算法版本。

## 调用示例

只有问题时不填写 `casting_method`：
~~~json
{"question":"我这次应聘能被录用吗？","topic":"career_position","subject_relation":"self"}
~~~
返回待选择状态。用户选择默认时间法后，在同一问题上增加：
~~~json
{"question":"我这次应聘能被录用吗？","topic":"career_position","subject_relation":"self","casting_method":"time_traditional"}
~~~
输入文件或标准输入交给 `python scripts/casting_cli.py --input - --output -`。方法ID由模型整理，不要求用户学习JSON字段。
